# Internationalization

## Locales

| Code | Language | Notes |
|------|----------|-------|
| `en` (default `values/`) | English | Source strings |
| `ar` (`values-ar/`) | Arabic | Full RTL |

## Conventions

- No hardcoded UI copy in Kotlin — use `stringResource` / `getString`
- QR / URI payloads are language-agnostic
- Compose follows `AppLocale` override when set; otherwise system locale
- Arabic uses RTL via `LayoutDirection.Rtl` when locale is `ar`

## Language override

Settings → Language: System / English / العربية. Preference key `app_locale` (`system` | `en` | `ar`).
